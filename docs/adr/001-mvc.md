# ADR 001: MVC и серверный HTML

Принято 21.10.2026. Сохраняем обязательный стек задания и MVC.
Model: PostgreSQL через pgxpool, без зависимости от Gin. Controller: HTTP, формы, права.
View: html/template и Bootstrap. Без ORM, SPA, REST API и DI-контейнера.
Goose запускается до приложения; PostgreSQL должен пройти healthcheck.
Проверки поведения: HTTP + отдельная PostgreSQL, браузер и CLI администратора.
Сессии: 32 случайных байта, SHA-256 в БД, TTL 24 часа. CSRF для каждого POST.
Ошибки: чужая задача 404, запрет админки 403, форма 422, недоступность БД 503.
Все TIMESTAMP интерпретируются в Europe/Moscow; пустой срок означает NULL.
