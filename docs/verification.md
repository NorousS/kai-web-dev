## Браузер

Playwright CLI + Chrome, локальное приложение http://127.0.0.1:8080.
IAB-подключение недоступно, использован явный fallback.

- Регистрация и вход через формы; создание задачи со сроком/приоритетом, редактирование статуса.
- Комментарий отображается после отправки. Поиск вместе со статусом сохраняет URL-параметры.
- Профиль сохраняет новое имя. Удаление своей задачи требует подтверждения; после удаления 404.
- Второй браузерный контекст обычного пользователя получает 404 на чужую задачу.
- Администратор создан CLI, входит через форму, видит пользователей и чужую задачу без возможности редактирования.
- Блокировка закрывает открытую пользовательскую сессию; после разблокировки первый вход успешен.
- Администратор удаляет чужую временную задачу, повторное открытие даёт 404.
- Viewport 1440x1000 и 390x844; document.scrollWidth не превышает innerWidth.
- Снимки: .scratch/desktop-tasks.png, mobile-tasks.png, desktop-admin.png, mobile-admin.png (локальные артефакты).
