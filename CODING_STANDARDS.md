# Стандарты

Простые функции и явная обработка ошибок; Model не импортирует Gin.
SQL параметризован, права владельца проверяются в SQL изменения.
Пользовательский текст передаётся шаблонам обычными строками.
Тесты проверяют HTTP/CLI-поведение, без моков внутренних репозиториев.
Каждая история: failing test, minimal implementation, tests, review, local commit.
Проверки: gofmt, go build ./..., go vet ./..., go test ./... с тестовой PostgreSQL.
При непрохождении проверок история не считается готовой.
