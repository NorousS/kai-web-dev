# PRD: Task Manager

## Цель
Учебный менеджер собственных задач, комментариев и профиля, с ролью администратора.
Go + Gin + PostgreSQL + Go Templates + Bootstrap, MVC, SSR без REST API.
Запуск docker compose up --build. Русский интерфейс.

## Решения
Model использует pgxpool; миграции goose до старта app. users, tasks, comments, sessions.
Пользователь видит и комментирует только собственные задачи. Администратор просматривает
и удаляет любые задачи и блокирует обычных пользователей. Профиль: имя и email.
Дата: Europe/Moscow, пустой срок NULL; прошедший срок допустим. Новые задачи первыми.
Нормализация email: trim+lower; уникальность в PostgreSQL. Пароли не trim.
Сессия: 32 случайных байта, SHA-256 в БД, абсолютный TTL 24 часа.
Все POST, включая регистрацию/вход/выход, защищены CSRF. Cookie HttpOnly/SameSite=Lax; Secure при HTTPS.
Чужая задача 404; неадмин в админке 403; гость перенаправляется на login; форма 422; БД недоступна 503.
Не возвращать SQL/пароли в HTML. Пользовательский HTML экранируется.

## Вне объёма
Публичный деплой, восстановление/смена пароля, подтверждение email, уведомления, вложения.

## Проверки
Основной seam: HTTP+изолированная PostgreSQL; browser для форм, CLI для администратора.
Тесты: положительные сценарии, границы значений, права двух пользователей, CSRF, сессии, блокировка.
Ralph: red→green→review→проверки→локальный commit; passes только после проверки.
AI-review архитектуры и acceptance criteria пройден до реализации.
