Справка

Проекты и роли

Владелец проекта управляет участниками, назначает управляющих и может передать владение. Управляющие создают задачи и проверяют выполнение. Участники работают с назначенными задачами.

Выполнение задачи

Исполнитель начинает работу, прикрепляет описание выполненного и/или ссылку на результат, затем отправляет на проверку. Другой управляющий одобряет работу или возвращает её на доработку. Напрямую завершить задачу нельзя.

Приоритеты

Базовый приоритет назначается вручную. По мере приближения дедлайна отображаемый приоритет повышается: 7 дней — средний, 3 дня — высокий, 24 часа — критический. Основной приоритет в базе не меняется. Индикатор срока можно изменить вручную.

Технологии

Серверная MVC-архитектура: Go, Gin, HTML-шаблоны, GORM, PostgreSQL, JWT, Docker и Swagger. HTML формируется на сервере; JavaScript для работы приложения не нужен.
